# LP-PDBBind 外部模型对比结果

本报告补充六个外部架构与项目完整前融合模型的对比结果。六个外部架构为
3DProtDTA、GraphDTA GIN、DeepDTAGen、TankBind、CASTER-DTA 和
AttentionMGT-DTA。结果来源、训练协议和封存信息见
[`LP_PDBBind_external_fair_test_plan.md`](LP_PDBBind_external_fair_test_plan.md)
以及 [`sealed_seven_test_20261017.json`](../snapshots/external_models/sealed_seven_test_20261017.json)。

## 3. 共同 test key 复算

这是封存的七模型回顾性 test 评估。规范 test 共 4,751 条，七者共同 key
为 4,291 条，所有指标均在这同一组 key 上统一计算；`原生 n` 只表示模型
自己的覆盖范围。当前 test 已在历史实验中被查看，因此 `blind_test=false`，
结果不能称为新的盲测。

| 模型 | 原生 n | 共同 CI | RMSE | MAE | Pearson | Spearman |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 3DProtDTA | 4,730 | 0.645769 | 1.777866 | 1.353088 | 0.419061 | 0.416135 |
| GraphDTA GIN | 4,730 | 0.648779 | 1.611508 | 1.270908 | 0.396198 | 0.438160 |
| DeepDTAGen | 4,730 | 0.613192 | 1.725266 | 1.362701 | 0.354819 | 0.329803 |
| TankBind | 4,751 | 0.683456 | 1.594229 | 1.255389 | 0.559531 | 0.524701 |
| CASTER-DTA | 4,687 | 0.660613 | 1.524568 | 1.219446 | 0.482481 | 0.466094 |
| AttentionMGT-DTA | 4,310 | 0.578046 | 1.770995 | 1.372703 | 0.239911 | 0.233039 |
| FullChainESMMSAAll v2（独立单模型） | 4,751 | **0.693874** | **1.411701** | **1.109051** | **0.584885** | **0.550258** |

在这个固定共同 test 子集上，独立 FullChainESMMSAAll v2 的五项指标均高于
六个外部候选。该结论只适用于已封存的单种子运行和各自输入条件：TankBind
使用原生配体位姿/口袋信息，AttentionMGT-DTA 使用预训练 ESM2 输入，其他
架构的输入和可用样本也不同。因此该表是统一 key 的结果对照，不是等输入、
等训练池或多种子统计意义上的纯架构排名。

当前最终前融合模型在官方 joined test 的结果仍以消融总表为准：CI
0.691291、RMSE 1.442721、MAE 1.142213、Pearson 0.569881、Spearman
0.545449（4,751 条）。它与上表的 FullChainESMMSAAll v2 是不同模型，不能
互换名称或指标。

## 4. 复核边界

- 所有共同 key 结果按 key join 后由同一指标函数计算，避免不同模型覆盖范围
  造成的直接误判。
- 外部模型结果只保留汇总指标、协议和 provenance；本分支不上传 checkpoint、
  特征缓存、数据集或逐样本预测数组。
- test 结果是回顾性比较，不参与候选选择、训练或模型升级。
- 原生覆盖、训练池、预训练输入和结构输入差异必须与指标一起报告。
